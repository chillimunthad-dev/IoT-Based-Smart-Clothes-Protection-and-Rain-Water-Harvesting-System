IoT-Based Smart Clothes Protection and Rainwater Harvesting System

Project Overview

This project is designed to protect clothes from rain automatically and collect rainwater for future use using IoT technology.

Objectives

- To protect drying clothes from unexpected rainfall.
- To collect and store rainwater in a storage tank.
- To alert users when the water tank is full.

Components Used

- ESP32 Microcontroller
- Rain Sensor
- Servo Motor
- Water Level Sensor
- Buzzer
- LED
- Connecting Wires
- Arduino IDE

Working Principle

1. The rain sensor detects rainfall.
2. The ESP32 receives the rain signal.
3. The servo motor automatically closes the protective cover over the clothes.
4. Rainwater is collected and stored in a tank.
5. When the tank reaches its full level, the buzzer turns ON to alert the user.

Applications

- Smart homes
- Automatic clothes protection
- Rainwater harvesting systems
- Water conservation
